# Security policy

## Supported versions

**partialid** is currently on a 0.x alpha train. Security fixes land on `main`
and ship in the next pre-release / release.

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security reports.

Prefer a [private GitHub security advisory](https://github.com/alexisbellot/partialid/security/advisories/new)
on this repository, or email the maintainer listed in `pyproject.toml`.

We will acknowledge receipt and work on a fix or disclosure timeline as
appropriate for the severity.
