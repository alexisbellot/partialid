# Citing partialid

If you use **partialid** in academic work, please cite the software below.
For the graphical criterion, cite the accompanying manuscript. Also cite the
methodological sources for the assumptions you rely on.

## Software

GitHub / Zenodo citation metadata: [`CITATION.cff`](https://github.com/alexisbellot/partialid/blob/main/CITATION.cff).

```bibtex
@software{partialid,
  title        = {partialid: Partial identification by composing assumptions for discrete causal models},
  author       = {Bellot, Alexis},
  year         = {2026},
  url          = {https://github.com/alexisbellot/partialid},
  version      = {0.1.0a5}
}
```

## Manuscript

```bibtex
@unpublished{bellot2026graphical,
  title        = {A Graphical Criterion for Linear Causal Bounds},
  author       = {Bellot, Alexis},
  year         = {2026},
  note         = {Manuscript},
  url          = {https://github.com/alexisbellot/partialid/blob/main/A%20Graphical%20Criterion%20for%20Linear%20Causal%20Bounds.pdf}
}
```

## Methods

Please also cite the methodological sources for the assumptions and algorithms
you rely on (e.g. Manski bounds, Tan MSM, Balke–Pearl IV,
symbolic/numeric bounds).
