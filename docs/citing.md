# Citing partialid

If you use **partialid** in academic work, please cite both the software and
the accompanying theory / paper when applicable.

## Software

GitHub / Zenodo citation metadata: [`CITATION.cff`](https://github.com/alexisbellot/partialid/blob/main/CITATION.cff).

```bibtex
@software{partialid,
  title        = {partialid: Partial identification by composing assumptions for discrete causal models},
  author       = {Bellot, Alexis},
  year         = {2026},
  url          = {https://github.com/alexisbellot/partialid},
  version      = {0.1.0a5}
}
```

## Methods

Please also cite the methodological sources for the assumptions and algorithms
you rely on (e.g. Manski bounds, Tan MSM, Balke–Pearl IV,
symbolic/numeric bounds).
